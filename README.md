# FleetCheck

FleetCheck is a web-based vehicle inspection and maintenance tracking application designed for commercial drivers, fleet managers, small businesses, and individual vehicle owners.

## Project Description

Many companies still rely on paper inspection forms or spreadsheets to track vehicle maintenance and inspections. FleetCheck provides a centralized digital solution that allows users to manage vehicles, perform inspections, and keep maintenance records organized.

This project is being developed as a Computer Science Capstone project.
